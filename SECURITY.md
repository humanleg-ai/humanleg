# Security Policy

## Supported versions

Only the latest minor release receives security updates during the 0.x series.

## Reporting a vulnerability

Do not open a public issue for suspected vulnerabilities. Email `security@humanleg.ai` with a clear
description, reproduction steps and impact. Do not include real identity data, credentials, payment
details or private task evidence.

We aim to acknowledge reports within three business days. This repository is a sandbox developer
toolkit and does not authorize testing against HumanLeg.ai production or third-party systems.
