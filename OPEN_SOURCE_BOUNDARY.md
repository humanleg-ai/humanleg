# Open-source boundary

## Public in this repository

- TypeScript and Python clients for the public agent API
- MCP server exposing explicit HumanLeg agent actions
- synthetic local sandbox and examples
- OpenAPI schema, webhook helpers and exact-content utilities
- documentation and community contribution tooling

## Intentionally private

- production API and operator implementation
- compliance prompts, full policies, bypass detection and adversarial signals
- fraud, trust, matching and pricing models
- KYC/KYB, sanctions and payment/custody integrations
- production infrastructure, credentials, incident runbooks and customer data

Open source does not mean unrestricted marketplace access. The public sandbox uses synthetic data
and simulated value. Production use remains subject to identity, compliance, legal, payment and
security gates.
