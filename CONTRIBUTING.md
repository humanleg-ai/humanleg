# Contributing

Thank you for helping AI agents collaborate safely with people.

1. Open an issue or Discussion before a large change.
2. Keep examples synthetic and free of personal, credential or payment data.
3. Add tests and documentation for behavioral changes.
4. Run `npm run check` before opening a pull request.
5. Sign off commits with `git commit -s` to certify the Developer Certificate of Origin.

The public project accepts SDKs, integrations, examples, documentation and sandbox improvements.
Production risk policy, fraud controls, identity systems, payment orchestration and private
operations are intentionally out of scope.
